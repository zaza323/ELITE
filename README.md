# موقع إيليت للرعاية الطبية

موقع ثابت (HTML / CSS / JavaScript) باللغتين العربية والإنجليزية، جاهز للنشر كما هو.

## النشر
ارفع محتويات هذا المجلد كاملة إلى الاستضافة (Netlify أو أي استضافة عادية)، والصفحة الرئيسية هي `index.html`.

## تعديل النصوص
- النصوص العربية: `languages/ar.json`
- النصوص الإنجليزية: `languages/en.json`
