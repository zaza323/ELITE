# موقع إيليت للرعاية الطبية

موقع ثابت (HTML / CSS / JavaScript) باللغتين العربية والإنجليزية، جاهز للنشر كما هو.

## النشر
ارفع محتويات هذا المجلد كاملة إلى الاستضافة (Netlify أو أي استضافة عادية)، والصفحة الرئيسية هي `index.html`.

## تعديل النصوص
- النصوص العربية: `languages/ar.json`
- النصوص الإنجليزية: `languages/en.json`

## صور تحتاج إلى استبدال لاحقًا
- صورة د. منى شعراوي: `assets/img/team/dr-muna-shaarawi.jpg` (صورة مؤقتة حاليًا، وتُستبدل بملف يحمل الاسم نفسه).
- صورة د. ناصر الرواشدة ود. محمد أبو غالي: `assets/img/team/other.jpg` (صورة مؤقتة).

## النماذج
ترسل نماذج الحجز والتواصل إلى `Info@elitejordan.com` عبر خدمة FormSubmit. عند وصول أول رسالة، تصل رسالة تفعيل من FormSubmit إلى هذا البريد، ويجب الضغط على رابط التفعيل.
